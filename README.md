# 하트챗 글 발췌기

트위터용 발췌 이미지를 만드는 도구예요. 문자창, 문장, 아이폰 메모장, 영상통화 화면을 PNG로 저장하거나 복사할 수 있어요.

## GitHub Pages로 올리기

1. 새 저장소를 만들고 이 폴더 안의 파일을 모두 올려요. `index.html`과 `fonts` 폴더가 저장소 맨 위에 있어야 해요.
2. 저장소의 **Settings → Pages**로 가요.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장해요.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열려요.

## 참고

- 설정과 프리셋은 쓰는 브라우저에 저장돼요. 다른 기기에서는 따로 저장돼요.
- `fonts/pretendard` 폴더는 프리텐다드 글꼴이에요(SIL Open Font License, `OFL.txt` 참고). 지우면 프리텐다드가 안 나와요.
- 다른 글꼴은 Google Fonts에서 불러와요.
